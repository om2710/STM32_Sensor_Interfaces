# STM32 Blue Pill – Sensor Interfaces

Collection of small STM32F103C6T6 sensor-interface examples used while developing the Blue Pill projects.

## Covered Interfaces
- ADC-based analog sensor reading
- Digital sensor input
- GPIO-controlled buzzer/LED
- I2C peripheral for OLED display

## Core Concepts
ADC converts an analog sensor voltage into a digital value. GPIO reads digital sensors and controls LEDs/buzzers. I2C provides a two-wire interface for the SSD1306 OLED.

This folder is intended as a reusable starting point for STM32 sensor projects.
